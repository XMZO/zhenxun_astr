# 签到模板编辑器

这是一个以原版模板为基线的本地可视化编辑器。它不会写入 `main.py`、根目录的 `sign_card.html`、`sign_card.css` 或 `assets/sign`；生成结果作为新的独立模板包安装。

## 启动

Windows 下可以直接双击 `start_editor.cmd`，脚本会启动服务并自动打开浏览器。关闭脚本窗口或按 `Ctrl+C` 即可停止。

在 `template_editor` 目录运行：

```powershell
uv run editor_server.py
```

打开 `http://127.0.0.1:8780/`。如果端口被占用，可以指定其他端口：

```powershell
uv run editor_server.py --port 8781
```

## 编辑范围

- 内容：预览昵称、UID、签到次数、温度、日期、两种卡片模式、运行文字、奖励/信息行、好感度预留区和时段文案池。
- 素材：头像、日历、角色、爱心、6 个标签、12 个天气图标和 5 个 WOFF2 字体。每一项都可以选中并定位到画布；标签和天气会自动切换为所选预览。图片上传会统一转换成 PNG。
- 图层：原版每个主要图片、文字、色块和进度条都可以独立调整位置、尺寸、旋转、缩放、透明度、层级、颜色、字体、圆角、滤镜和阴影。
- 自定义图层：可以增加任意数量的文字层和图片层；图片在生成包中会内嵌，不依赖编辑器服务。
- 高级 CSS：追加到模板样式末尾，允许继续覆盖未暴露在面板中的 CSS 属性。

画布会在每次修改后重新渲染，选中元素可以直接拖动，也可以通过选区四边和四角的手柄拉伸宽高；按住 `Shift` 拖动角点会保持宽高比。鼠标悬停会显示虚线轮廓；选中后会按元素的实际渲染边界显示醒目的定位框、中心点、坐标和尺寸，移动、拉伸、缩放或旋转时会实时跟随。一次拖动只生成一个撤销步骤，撤销/重做支持快捷键 `Ctrl+Z`、`Ctrl+Y`，`Ctrl+S` 导出项目 JSON。

## 生成与恢复

先在“模板包信息”填写对外显示的名称和说明。内部 ID 会自动生成为随机 UUID，不显示在编辑器或机器人模板列表中。点击“生成模板”会：

- 在 `template_editor/output/<时间戳>-<模板ID>-<随机值>/` 创建独立目录和 ZIP。
- 自动安装到插件的 `template_packs/<随机内部ID>`。
- 把该模板的文字、样式和素材写入包内，不生成需要手工合并的 AstrBot 配置。
- 在弹窗中显示模板名称和 `切换签到模板 <模板名称>` 命令。
- 在每个模板包内写入独立 `README.md` 安装教程。

随机内部 ID 用于避免覆盖已有模板；同名显示名称允许共存，同名时可通过 `签到模板` 返回的 `#序号` 切换。AstrBot 每次使用模板时都会重新发现文件夹和 ZIP，因此通常不需要重载插件。

要把模板迁移到其他 AstrBot 实例，打开目标实例的 `插件管理 -> 真寻签到 -> 插件配置`，在“签到模板管理”上传 `output` 中的 ZIP 并保存。插件会校验、安装并默认自动应用新模板，不需要手工修改配置 JSON。

点击“恢复原版”只重置编辑器状态、预览和本地草稿，不删除上传素材，也不触碰现有插件。项目可以通过“导出项目”和“导入项目”携带素材往返。

`default_state.json` 是编辑器的原版基线。`workspace` 只保存上传素材；`output` 是可下载和迁移的生成副本，实际自动安装位置是 `template_packs`。
