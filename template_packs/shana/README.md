# 夏娜签到模板

这是由 `template_editor` 生成的自包含签到模板包。文字、样式和素材均保存在本目录内。

## 安装

1. 保持本目录中的 `template.json`、`sign_card.html`、`sign_card.css` 和 `assets/sign` 结构不变。
2. 搬到其他实例时，将整个文件夹复制到 `zhenxun_astr/template_packs`；对应 ZIP 也可以直接放入该目录，无需解压。
3. 发送 `签到模板` 确认发现。
4. 管理员发送 `切换签到模板 夏娜`，然后发送 `签到` 验证。
5. 若存在同名模板，根据列表发送 `切换签到模板 #序号`。

## 说明

- 内部 ID 仅用于兼容和唯一识别，不作为显示名称。
- 无需合并或替换 AstrBot 插件配置。
- `editor_state.json` 仅用于重新导入编辑器继续修改。
