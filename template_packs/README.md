# 签到模板包安装说明

每个子文件夹或 ZIP 是一套独立签到模板。插件会自动发现新增内容。

## 安装

推荐在 AstrBot WebUI 打开 `插件管理 -> 真寻签到 -> 插件配置`，在“签到模板管理”上传 ZIP，然后点击配置页底部的“保存”。插件会安全校验并安装模板，默认自动应用最后一个新模板。

也可以手动安装：

1. 文件夹包必须保留 `template.json`、`sign_card.html`、`sign_card.css` 和 `assets/sign` 的相对结构。
2. 将整个模板文件夹放入本目录；ZIP 包也可以直接放入本目录，无需解压。
3. 发送 `签到模板` 确认发现结果。
4. 管理员发送 `切换签到模板 <模板名称>`，然后发送 `签到` 验证。
5. 如果存在同名模板，根据列表发送 `切换签到模板 #序号`。

## 说明

- `template.json` 中的随机内部 ID 只负责唯一识别，不会显示在机器人模板列表中。
- 当前选择保存在插件数据目录的 `active_template.txt`，无需修改 AstrBot 配置。
- 无效模板包会被忽略，内置官方默认模板不会被覆盖。
- 设置页上传源和已安装模板是独立副本；从上传列表删除源文件不会卸载模板。

推荐通过 `template_editor` 生成；编辑器会自动安装到本目录，并在 `template_editor/output` 保留可迁移的 ZIP。
